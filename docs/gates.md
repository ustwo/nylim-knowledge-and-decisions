# Stages and gates

An optional way to say where in the person's journey something sits. Tag a decision, hypothesis, finding, KPI or objective with a `stage`, a `gate`, or neither. Nobody has to use them. When they're used, the [view by stage](_generated/by-stage.md) gathers everything for one stage or gate in one place: "what do we know about sign-up?"

## Stages

The four stages of the engagement loop. They're fixed, so every project uses the same words.

| Stage | Means |
|---|---|
| `activate` | Someone finds {{Product}} and gets started |
| `motivate` | They see enough value to commit |
| `sustain` | They keep coming back, and it becomes a habit |
| `change` | They do more, or it changes how they work |

## Gates

The decision points a person passes through, each in one stage. A gate is where someone decides whether to go on, such as signing up for a plan. Tagging a gate implies its stage, so there's no need to tag both.
